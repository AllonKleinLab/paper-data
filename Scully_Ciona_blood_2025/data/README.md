To run scripts in this repo subfolder `Scully_Ciona_blood_2025`, download the following scRNA-seq datasets to this subfolder:

#### For all scripts
- _C. robusta_ blood processed dataset. Downloadable from GEO: [https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE296253](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE296253), download file `GSE296253_combined_processed_data.h5ad`.

#### For scripts in the `species_comparisons` subfolder

- Human blood and bone marrow dataset (Tabula Sapiens). A version of this dataset ready to use with scripts in this repo can be downloaded from Zenodo ([link](https://zenodo.org/records/17209147)): within scripts.zip, the human dataset counts matrix can be found under `zenodo_files/data/Hs_Tabula_Sapiens_blood_bone_marrow.h5ad`. The original dataset files can be found here: [https://figshare.com/articles/dataset/Tabula_Sapiens_release_1_0/14267219](https://figshare.com/articles/dataset/Tabula_Sapiens_release_1_0/14267219), and cell annotations used are in Table S5 of our paper.

- Zebrafish kidney marrow dataset (Wang et al. 2024, doi:10.1038/s41467-024-51761-4). A version of this dataset ready to use with scripts in this repo can be downloaded from Zenodo ([link](https://zenodo.org/records/17209147)): within scripts.zip, the zebrafish dataset counts matrix can be found under `zenodo_files/data/Dr_zfish_kidney_marrow_Wang.h5ad`. The original dataset files can be found in the Genome Sequence Archive CRA017585, and cell annotations used are in Table S5 of our paper.
